# Haze Check SG

A static, single-page site that tells people in Singapore how hazy it is, what to do about it, and how the
haze has changed over the past week. It is aimed at the general public, not data specialists.

## How it fits together

```
src/page.html        Page template: HTML, CSS and JS in one file. /*SHAPES*/ is replaced at build time.
src/regions.json     SVG outlines of NEA's five regions (generated by scripts/make_regions.py).
data/nea.json        Hand-written summaries of NEA's daily Haze Situation Updates. Source of truth.
public/data.json     Hourly PSI/PM2.5 by region, Changi weather, NEA summaries. Read by the page at load.
public/index.html    Built page. Do not edit by hand; edit src/page.html and rebuild.
scripts/fetch.py     Pulls PSI from data.gov.sg and Changi weather reports, merges into public/data.json.
scripts/merge.py     Merges new readings/NEA entries into data.json (keeps the last 21 days).
scripts/build.py     Builds public/index.html and syncs data/nea.json into public/data.json.
tests/               Offline tests (no network): python3 -m unittest discover tests
.github/workflows/   update-data.yml runs fetch+build twice daily and commits; deploy-pages.yml publishes public/.
```

## Commands

```bash
python3 scripts/fetch.py            # yesterday + today; --days 7 for a week; --date 2026-09-29 for one day
python3 scripts/build.py            # rebuild public/index.html after editing src/page.html or data/nea.json
python3 -m http.server -d public    # preview at http://localhost:8000 (the page fetches data.json, so open it over http)
python3 -m unittest discover tests  # run tests
```

No dependencies beyond the Python standard library (shapely only for make_regions.py).

## Data formats

- `public/data.json` → `psi["YYYY-MM-DDTHH"] = [[psi n,s,e,w,c], [pm25 n,s,e,w,c]]` (24-hour values, SGT hours).
  `wx["YYYY-MM-DDTHH"] = [wind_dir, wind_kmh, temp_C, humidity_%, visibility_m, rain 0-3, thunder 0/1, pressure_hPa, haze 0/1]`.
  Wind is stored but deliberately not shown (one station only; see copy rules).
- `data/nea.json` entries:
  `{"d":"YYYY-MM-DD","kind":"update","t":"6pm","psi":[lo,hi],"pm":[lo,hi],"fc":"Moderate – Low Unhealthy","wx":"fair|cloudy|dry|showers|heavy","wxt":"short phrase","wind":null,"src":["Sumatra","Kalimantan"],"sum":"1–2 sentences","url":"..."}`
  or `{"d":..., "kind":"notice", "title":..., "sum":..., "url":...}`.
  `psi` is the 24-hr PSI range and `pm` the 1-hr PM2.5 range from the update's "As at Xpm" sentence.

## Adding a new NEA update

NEA posts a "Haze Situation Update" most evenings while PSI is high, at
`https://www.nea.gov.sg/media/news/advisories/index/haze-situation-update-<d>-<month>-<yyyy>` (the slug format varies;
search the advisories page). Add an entry to `data/nea.json`, then run `python3 scripts/build.py`.
Summaries must use only facts stated in that update, in plain English, at most ~45 words.

## Copy rules (the page must not mislead)

- Health advice must match NEA's advisory table exactly in meaning (verified against MOH's haze FAQ):
  Good/Moderate: normal activities for everyone. Unhealthy: healthy reduce, vulnerable minimise, heart/lung avoid
  long or strenuous outdoor activity. Very unhealthy: healthy avoid long/strenuous; elderly, pregnant, children
  minimise outdoor activity; heart/lung avoid outdoor activity. Hazardous: healthy minimise outdoor activity;
  everyone else avoid outdoor activity.
- The headline level is the worst region's PSI. Always say so ("Worst area: …").
- PSI is a 24-hour average; point people to the 1-hour PM2.5 on haze.gov.sg / myENV for right-now decisions.
- Don't claim the data is live or updated on a schedule unless the update workflow is actually running.
- Weather is from one station (Changi Airport). Label it that way. Wind direction is intentionally not shown.
- Comparisons ("highest", "lowest") must say what they compare against, e.g. "in NEA's evening updates in September".
- Town lists per region are our own approximation, not an official NEA list.
- Never imply this is an official NEA or government service. Keep the Singapore Open Data Licence credit in the footer.

## Design

- Colour tokens live at the top of the `<style>` in src/page.html; light theme ("clear sky") is the default, dark via
  the header toggle (saved in localStorage) or `data-theme="dark"` on `<html>`.
- PSI band colours: `--good --mod --unh --vunh --haz`. Text on band colours is near-black, white above PSI 200.
- Charts are hand-written SVG that redraw to fit their container width; check at 375px wide before shipping.
